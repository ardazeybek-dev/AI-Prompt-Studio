How the real app works

The backend prompt — backend/main.py

FastAPI holds one endpoint. It wraps your idea in a system prompt and hands it to Llama 3.1 on Groq, which does the actual creative expansion the demo above only approximates.

# POST /api/generate
chat_completion = client.chat.completions.create(
    messages=[
        {
            "role": "system",
            "content": "You are a professional prompt engineer. Take the "
                       "simple idea you are given and turn it into a detailed, "
                       "cinematic, English image-generation prompt."
        },
        {"role": "user", "content": f"Idea: {request.text}"}
    ],
    model="llama-3.1-8b-instant",
)
return {"prompt": chat_completion.choices[0].message.content}
Run it locally 
# 1) Backend — needs a free Groq API key in backend/.env
cd backend
python -m venv venv && .\venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn main:app --reload      # :8000

# 2) Frontend
cd frontend
npm install
npm run dev                              # :5173

The key is read from .env and never committed — which is also why this page can't call the model on your behalf.
